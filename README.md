# 窗 · WINDOWSHOP — 橱窗陈列馆

纯静态网页，无需安装任何东西。

## 本地打开
双击 `index.html` 即可（数据已内置在 data.js，离线可用）。

## 上传到 GitHub Pages
1. 在 GitHub 新建仓库（如 `windowshop`）
2. 把本文件夹里的**所有内容**（index.html、style.css、main.js、data.js、assets/）上传到仓库根目录
3. 仓库 Settings → Pages → Source 选 `main` 分支根目录，保存
4. 稍等片刻访问 `https://你的用户名.github.io/windowshop/`

也可以直接部署到 Vercel / Netlify：把这个文件夹整个拖进去即可。

## 文件说明
- `index.html` 页面结构
- `style.css` 全部样式
- `main.js` 全部交互（雾气玻璃 / 3D 长廊 / 色块索引 / 档案筛选 / 拖拽文件夹 / 详情路由）
- `data.js` 176 个作品条目数据
- `assets/images/` 166 张作品图片
